⚽ Professional Sports Betting Odds Scraper
An advanced automation tool designed to extract real-time 1X2 odds from major football leagues. This project showcases high-level techniques to bypass modern anti-bot systems while gathering critical financial and sports data.


Key Technical Features:

+ Anti-Detection Engine: Utilizes undetected-chromedriver and customized User-Agent headers to hide automation fingerprints and mimic human browsing behavior.

+ Dynamic Data Extraction: Leverages multi-selector logic (CSS & XPath) to identify match names, start times, and odds across various site layouts.

+ Human-Like Interaction: Implements random delays (random.uniform) and automated scrolling to avoid IP blacklisting and connection resets.

+ Structured Output: Automatically cleans and exports live data into a professional live_odds.csv file for further statistical analysis.

+ Visual Dashboard: Uses colorama to provide a real-time, color-coded table in the terminal for instant market monitoring.
